# Captain Glassmart & Hardware

Nairobi's trusted supplier of hardware, glass, aluminium, furniture fittings, tools, adhesives, and finishing solutions.

## Tech Stack

- **React** 19
- **Vite** 8
- **Tailwind CSS** v4
- **React Router** v6
- **Lucide React** (Icons)

## Getting Started

### Installation

```bash
npm install --legacy-peer-deps
```

### Development

Start the development server:

```bash
npm run dev
```

### Build

Build for production:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```
